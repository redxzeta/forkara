## Compatibility

- Forkara package names, runtime environment, profile paths, MCP audience, URI/bundle identity, assets, release destinations, and copy-only legacy profile import remain Forkara-owned.
- MCP task reads accept optional message index/offset/identity/version fields so a long message can be read completely without silently crossing versions.
- `projects.file-watch` is optional. Old servers remain usable; subscriptions clean up on disconnect and resume on reconnect. Forkara's explicit GitHub provisioning v2 negotiation is retained.
- Migration 097 invalidates only the thread projection cursor so startup can rebuild its read model. Existing migration identities are unchanged; upstream sidechat and Kilo migrations are not included.
- Migration repair now binds consent to the inspected database/lineage. Newer-schema recovery requires a verified backup, preserving the current database on failure.
- TypeScript workspaces use the native TypeScript 7 checker with Effect integration. The Astro workspace keeps `astro check`; TypeScript 5 stays available for build tools and `typecheck:legacy`. This supersedes the initial plan's toolchain deferral following user approval.
